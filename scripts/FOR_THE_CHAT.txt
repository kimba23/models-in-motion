MAKE YOUR OWN SCRIPT WITH A CHAT
================================

1. In Claude or ChatGPT, paste the box below.
2. Paste a script that is close to your idea (open it in Notepad, copy all).
3. Write your idea in one sentence, in any language.
4. Save the answer in your folder of takes as  yourname.py
   (Notepad: "Save as type: All files", or it becomes yourname.py.txt).
5. Double-click RUN.bat. If it stops with an error, paste the error to the
   chat: "fix it". Save, RUN again.

------------------------------- the box -------------------------------------
Here is a Python script that edits AI video takes. Write a NEW one with the
same shape and my idea (at the end). The shape:
- One file. Only the standard library, numpy, cv2, PIL.
- It reads the .mp4 takes in its own folder: sorted(Path(__file__).parent.glob("*.mp4"))
- It writes .mp4 (cv2.VideoWriter) into a subfolder named after the script,
  and next to each video a .txt with the settings it used.
- For the sound: next to each video also a .frames file with the same name,
  one line per output frame: source frame number, a tab, the take's file name
  (several takes separated by tabs = mix their sound). Another program
  rebuilds the audio from it.
- Settings at the top in CAPITALS, one comment each.
- Short and readable. Print what it does.
